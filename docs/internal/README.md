# Internal docs — not product documentation

These are **internal working documents**: design notes, future-feature plans,
and historical audit snapshots. They are **not** part of the user-facing
documentation set and may be out of date.

**The code is the source of truth.** If a document here disagrees with the
current code, the code wins — verify against the code, not these notes.

User-facing docs live one level up in `docs/` (installation, features,
controls, architecture, mcp-setup) and in the repo root (`README.md`,
`CHANGELOG.md`).

| File | What it is |
|---|---|
| `REMEDIATION-2026-06-05.md` | A point-in-time audit-remediation tracker. Many items are since fixed; checkboxes were not all flipped. Historical reference only. |
| `L3-EXPRESSION-PLAN.md` | Design plan for a future Layer-3 (expression/dataflow) capability. Not implemented. |
